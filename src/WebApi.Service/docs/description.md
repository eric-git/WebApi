This Web API provides a minimal, modern ASP.NET Core service for managing a collection of games. It demonstrates clean endpoint design, lightweight configuration, and a straightforward CRUD workflow suitable for small services or as a foundation for larger systems.

To run the service locally or in a container:

- Clone the repository to your development machine.
- Open the solution using Visual Studio, Rider, or your preferred IDE.
- Run the project directly, or build and deploy it using Docker to start the API service.
